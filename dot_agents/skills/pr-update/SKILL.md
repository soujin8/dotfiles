# Pull Request Update

`gh` コマンドで現在のブランチの Pull Request の内容を更新する。

## 手順

1. **現ブランチのPRを特定する**: `git status --short` と現在のブランチ名を確認し、`gh pr view` で現在のブランチに紐づく Pull Request を確認する。
   - 対応する PR が存在しない場合は、その場で作成せず、ユーザーに PR が見つからない旨を伝えて `gh pr create` するか確認する。
2. **PRテンプレートを確認する**: `.github/PULL_REQUEST_TEMPLATE.md`、`.github/pull_request_template.md`、`.github/PULL_REQUEST_TEMPLATE/` 配下、または docs 直下などを探す。見つかった場合はその構成（見出し・チェックリスト）に従う。テンプレートがない場合は、既存 PR 本文の構成をそのまま踏襲する。
3. **差分を確認する**: `gh pr diff` またはベースブランチとの `git diff` で実際の変更内容を確認し、本文が現状の差分と食い違っていないか照合する。
4. **本文を生成する**: テンプレートまたは既存構成に沿って本文を組み立てる。「変更の意図」セクションを設け、なぜその変更が必要かを明確に書く。差分や既存説明から読み取れない意図は推測で埋めず、不明点はユーザーに質問してから反映する。
5. **更新前にユーザーへ確認する**: 生成した本文案を提示し、ユーザーの確認を得てから次のステップに進む。
6. **PRを更新する**: 承認後、`gh pr edit --body-file` などで PR 本文を更新する。

## 注意

- PR の既存本文に重要な情報（手書きのメモ、経緯、レビューコメントへの回答など）がある場合は消さずに統合する。
- 差分や既存説明から分からない意図は推測で埋めない。
- PR テンプレートのチェックリストや必須項目は維持し、内容が変わらない項目は書き換えない。
