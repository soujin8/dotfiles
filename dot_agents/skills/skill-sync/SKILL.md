# Skill Sync

個人スキルの正は `~/.local/share/chezmoi/dot_agents/skills/`。反映先は `~/.agents/skills/` で、Claude・Codex側はリンクまたは個別配置になっている。状態は実行時に確認する。

## 編集と反映

1. 対象スキルについて、正本・`~/.agents/skills/`・`~/.claude/skills/`・`~/.codex/skills/` の存在、symlink先、差分を確認する。ルート全体のリンクだけでなく、スキル単位のリンクも確認する。
2. 編集は正本に行う。反映先だけにある未同期の編集を見つけたら、内容を比較して保全し、根拠なく正本で上書きしない。
3. 変更した対象だけ `chezmoi diff --recursive <target>...` と `chezmoi apply <target>...` で反映する。`<target>` は `~/.agents/skills/<name>` などの反映先パス。一般設定を巻き込む無指定 apply は使わない。
4. リンク経由で更新される箇所は内容を読み返す。実体コピーは対象スキルの差分だけを確認し、既存の同期方式と今回の許可の範囲で更新する。

編集・同期がすでに依頼されていれば、書き換えの大きさだけを理由に承認を取り直さない。競合する変更の採否、未指定の削除、リンク構成の変更など、未確定の判断が必要な部分だけ内容と影響を示して確認する。必要な権限昇格は実行環境の承認機構に従う。

## 保持するもの

- `~/.codex/skills/.system/` などツール固有のスキル・ファイルは同期対象外にする。
- 正本にあるだけで未導入のスキルは、自動で全ツールへインストールしない。導入まで依頼された対象だけ追加する。
- 実体ディレクトリ全体の削除や `rsync --delete` は既定の同期手順にしない。リンク構成の変更が依頼された場合は、固有ファイル・ローカル変更の退避と復元手段を確保して対象限定で行う。
- 壊れたリンクはリンク先と管理元を確認する。正しい参照先を特定でき、修復が今回の範囲に含まれる場合に管理元から直す。

完了時は、正本で変更したスキル、反映できた配置、未反映・競合を簡潔に伝える。
